==============================================================
EVENT HUB (server_hub.py) - NETWORK & FIREWALL CHEAT SHEET
==============================================================

1. BYPASS ISP BLOCKS (FIX ".trycloudflare.com" NOT LOADING)
If your PC blocks Cloudflare URLs (common with Jio/mobile tethering), change Windows DNS manually. Do not use the modern Windows 10/11 Settings app, as it breaks USB tethering.
* Press [Win + R], type `ncpa.cpl`, and press Enter.
* Right-click your active internet adapter (e.g., USB Tethering/Wi-Fi) -> Properties.
* Double-click "Internet Protocol Version 4 (TCP/IPv4)".
* Select "Use the following DNS server addresses" and enter:
   - Preferred: 1.1.1.1
   - Alternate: 1.0.0.1
* Click OK twice.

2. DEEP NETWORK & DNS FLUSH (RUN AS ADMIN IN COMMAND PROMPT)
If the dashboard speedometer is stuck on "Offline", the network is glitching, or the old ISP block is cached, run these in Command Prompt (Admin):
* `ipconfig /flushdns`      (Clears Windows DNS cache)
* `ipconfig /release`       (Drops current IP)
* `ipconfig /renew`         (Requests a fresh IP from the router)
* `netsh winsock reset`     (Deeply resets network adapters -> REQUIRES PC RESTART)
* CHROME BROWSER CACHE: Go to `chrome://net-internals/#dns` and click "Clear host cache".

3. OPEN FIREWALL PORTS (FOR LOCAL LAN SCANNERS/KIOSKS)
To ensure mobile scanners on your local Wi-Fi can reach the Waitress engine (Port 5000) and HTTPS Cheroot engine (Port 5001), run this exactly in PowerShell (Admin):
* `New-NetFirewallRule -DisplayName "EventHub Ports" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 5000,5001`[cite: 2]

4. CLOUDFLARED TUNNEL RESETS (RUN AS ADMIN IN COMMAND PROMPT)
If the tunnel hangs, throws authentication errors, or you need to clear an old token configuration:
* `cloudflared service uninstall` (Wipes the background service/configs)
* `cloudflared update`            (Forces an update to the latest tunnel protocols)
